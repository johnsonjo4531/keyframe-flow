keyframe-flow

A headless, transform-first animation engine for the web: immutable transforms and matrices at its core, pure timeline sampling, an explicit playback state machine, and structural render targets for HTML, SVG, Canvas 2D, WebGL, and WebGPU.

Design principles

  • Runs anywhere JavaScript runs — the core never touches browser APIs.
  • Immutable values: transforms, matrices, and animations are never mutated in place.
  • Right-handed coordinates, column vectors, column-major matrices, radians only.
  • Sampling is a pure function of progress — drive your own render loop if you want.
  • Playback is explicit: one owner per render target, supersede semantics, no magic.
  • Render targets are structural — any object with setTransform(matrix) works.
